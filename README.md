# API Lighthouse Marketplace

Scaffold a modern API marketplace application called API Lighthouse using React, TypeScript, and Tailwind CSS.

1. Theme & Color Tokens:

Primary Navy Foundation: #0B1730

Primary Action Accent (Buttons): Deep Blue #2448D8

Link/Highlight Accent: Teal #087F8C

Backgrounds: Warm White #F7F9FC with clean white surface cards (12–16px rounded corners).

2. Header & Navigation (SiteHeader):

Logo: API Lighthouse

Navigation Links: Explore APIs (/apis), For Providers (/providers), Developers (/developers), Resources (/guides)

Secondary Actions: Log in (/login), Sign up (/signup)

Prominent Primary CTA Button: 'Publish your API' (/signup?intent=provider)

Include an accessible mobile drawer navigation (MobileNavigation)."
